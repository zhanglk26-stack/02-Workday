# 工作日看板 (2026 - 2027)

面向中国工作日历看板工具，完整支持 2026 与 2027 两年连续过渡，含法定节假日、调休补班安排与倒计时。部署于 Cloudflare Pages，零构建、零后端依赖。

## 功能

- **日历视图** — 单月 / 双月连看 / 两年图谱三种模式，标注工作日、周末、节假日与调休补班
- **连续跨年导航** — 像万年历一样平滑过渡，支持 2026-12 到 2027-01 顺畅翻页，双月模式下支持跨年并排显示
- **双年月份导航** — 左侧面板展示 2026 与 2027 两年全部 24 个月份，一键直达任意月份
- **工作进度** — 视口当月进度与年度完成度、工作天数与假期余额统计
- **节假日倒计时** — 动态计算距未来法定节假日还需的工作日天数
- **亮 / 暗主题** — 一键切换，记忆用户偏好

## 节假日数据

节假日和调休日期来源于国务院每年发布的官方通知，维护于 `workday.js` 中。

> 每年政府发布新通知后，只需更新 `workday.js` 中的 `DATA.h`（节假日）和 `DATA.w`（调休）两个对象即可。

## 文件结构

```
├── index.html      # HTML 结构
├── style.css       # 全部样式（含亮/暗主题、响应式）
├── app.js          # 应用逻辑（状态管理、日历渲染、跨年计算）
├── workday.js      # 工作日判断核心 + 2026/2027 年法定假期及调休数据
└── tests/
    └── workday.test.js   # 自动化单元测试（Node.js 内置 test runner）
```

## 本地运行

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

## 测试

```bash
node --test tests/workday.test.js
```

## 部署

推送到 Git 仓库后，Cloudflare Pages 自动部署。无需构建命令，发布目录设为根目录 `/` 即可。
